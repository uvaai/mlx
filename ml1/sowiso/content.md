
# SOWISO

All the mathematical material and exercises for this course will be
done in an online environment called SOWISO, which you may or may not already
be familiar with. In SOWISO you can read theory pages describing the concepts
and can get automated feedback and hints for each exercise.

Logging in to SOWISO can be done through [the following link](https://uva.sowiso.nl/auth/login).
You will be given access after the first in-person session.

**Note:** _Make sure to keep your language in SOWISO set to English, as some of the
modules will not be available in Dutch._

## Mathematical foundations

During the course, each module will link to one or more chapters in SOWISO for you to complete that week.

This module we'll get started with the basic concepts of probability and
data, and some basic elements from statistics and data science.
which will be useful when working with different data sets

Complete *Chapter 1. Probability* and *Chapter 2. Describing Data*.

Since all the exercises have automated feedback, your answers in the SOWISO
will not be graded. _If you're already familiar with the topics in a chapter,
you may skip these exercises, but please check to make sure you can do all
of the exercises before starting the theory of the next module._
